4 · Push to Google Sheets

Send confirmed names from your saved photo batches into the Scanner_Intake tab of your MTG Commander Master Database. Repeated pushes check batch/position IDs and skip previously imported rows. This does not update Collection or Deck_Cards automatically.

First-time setup: Google OAuth client (required)
  1. Open Google Cloud credentials, choose or create a Google Cloud project, and enable the Google Sheets API.
  2. Configure the Google Auth Platform consent screen. For a personal project, use External testing and add your Google account as a test user if required.
  3. Create an OAuth client ID → Web application, and add https://cbdragons.github.io to Authorized JavaScript origins. You do not need a redirect URI for this browser popup token flow.
  4. Paste your OAuth client ID below (not a client secret), and paste the URL of your existing MTG Commander — Master Database Google Sheet.
  5. Tap Save settings, Connect to Google, and Test destination. Sign in to the Google account that can edit your Master Database.
  6. Once you have saved at least one reviewed photo batch locally, tap Push saved batches. Check readback results before treating the import as complete.

Never paste a client secret, API key, Google password, personal access token, or downloaded service-account JSON here. A public OAuth client ID is expected. Authorization happens directly with Google; access tokens stay in memory and are not committed to GitHub or written to browser storage.
